# CS SCM VFX — Mapa Operacional Médico

Repositório para publicação dos Mapas Operacionais Médicos do Campus de Saúde SCM VFX.

## Segurança

Este repositório deve permanecer **PRIVADO** antes de receber qualquer ficheiro com dados clínicos identificáveis. O site Netlify também deve ter controlo de acesso próprio antes da publicação de mapas reais.

## Estrutura

- `index.html` — página inicial/arquivo
- `mapas/` — mapas operacionais HTML
- `assets/style.css` — estilos partilhados
- `netlify.toml` — configuração de headers/cache

Fluxo previsto: Excel → geração HTML → commit GitHub → deploy Netlify.
